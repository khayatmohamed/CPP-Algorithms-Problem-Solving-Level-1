
# C++ Algorithms & Problem Solving – Level 1

## Problems #31 to #35 – Solutions

### 📌 Overview

This folder contains my C++ solutions for Problems #31 to #35 from **Algorithms & Problem Solving – Level 1**.

The purpose of these exercises is to strengthen my programming fundamentals, mathematical thinking, conditional logic, and problem-solving skills.

These problems focus on power calculations, grade evaluation, sales commissions, and calculating money using structures and functions.

## 🚀 How to Run

1. Download or clone the repository.
2. Open `Solutions.cpp` in Microsoft Visual Studio.
3. Navigate to the `main()` function.
4. Uncomment the code section for the problem you want to execute.
5. Comment out the other problem sections.
6. Compile and run the program.

**Note:** Only one problem should be active in `main()` at a time.
