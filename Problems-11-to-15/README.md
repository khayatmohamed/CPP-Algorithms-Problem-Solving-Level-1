
# Algorithms & Problem Solving - Level 1 (C++) 

A collection of beginner-friendly C++ programming exercises
focused on improving algorithmic thinking, problem-solving
skills, and writing clean, structured code.

## About This Repository

This repository contains my solutions to exercises from
the Algorithms & Problem Solving - Level 1 course.

Each problem is solved using functions to separate
input, processing, and output.

The goal is to build a strong foundation in C++
programming and problem-solving.

## Problems Covered

| Problem | Description |
|---------|-------------|
| #11 | Calculate the average of three marks and determine Pass or Fail |
| #12 | Find the maximum of two numbers |
| #13 | Find the maximum of three numbers |
| #14 | Swap two numbers using references |
| #15 | Calculate the area of a rectangle |

## Concepts Practiced

- Variables and data types
- Input and output using cin and cout
- Functions and return values
- Parameters passed by value and reference
- Conditional statements (if / else)
- Switch statements
- Enumerations (enum)
- Loops and basic input validation
- Arithmetic operations
- Breaking problems into smaller functions

## How to Run

### Requirements

- A C++ compiler (G++, MSVC, or Clang)
- Visual Studio, VS Code, or any C++ IDE

### Compile Using G++

```bash
g++ -std=c++11 main.cpp -o algorithms
```

### Run on Windows

```powershell
.\algorithms.exe
```

### Run on Linux / macOS

```bash
./algorithms
```

## Problem-Solving Approach

For each exercise, I follow these steps:

1. Understand the problem.
2. Identify the required inputs.
3. Determine the processing logic.
4. Implement reusable functions.
5. Display the expected output.
6. Test the solution with different values.
