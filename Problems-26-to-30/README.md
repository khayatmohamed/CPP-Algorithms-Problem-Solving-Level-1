
# C++ Algorithms & Problem Solving – Level 1

## Problems #26 to #30 – Solutions

### 📌 Overview

This folder contains my C++ solutions for Problems #26 to #30 from **Algorithms & Problem Solving – Level 1**.

The purpose of these exercises is to strengthen my programming fundamentals, logical thinking, loop control, and problem-solving skills.

These problems focus on using **for, while, and do-while loops**, working with odd and even numbers, and performing factorial calculations.

## 🚀 How to Run

1. Download or clone the repository.
2. Open `Solutions.cpp` in Microsoft Visual Studio.
3. Navigate to the `main()` function.
4. Uncomment the code section for the problem you want to execute.
5. Comment out the other problem sections.
6. Compile and run the program.

**Note:** Only one problem should be active in `main()` at a time.
